TO-BE 개선 사항
  • 신규 현황 · 비교 · 히트맵 3화면을 한 페이지 탭으로 통합 — 업체/기간 필터를 공유하므로 같은 지표를 다시 조회할 필요가 없습니다.
  • 신규 증감을 방향(▲▼) + 색 + 막대 비율로 동시 표기(.eff 직전/기준 2행 + DIFF)해 크기까지 즉시 인지.
  • 신규 히트맵에 5단계 색상 범례와 주말/휴일(집계 제외) 표기를 추가하고, 운영률 ↔ 운영효율 토글을 제공.
  • 신규 비교 대상 업체를 칩(chip) 추가/삭제로 관리하여 해당 업체 행만 부분 갱신(전체 재조회 제거).
  • 신규 내보내기(Excel/CSV) — 지표·기간·업체 범위를 선택해 다운로드.
  • 신규 8개 지표 기간별 추이 그래프를 현황 탭에 함께 배치(운영률·운영효율 라인 + 6지표 막대).
  • 유지 STD / PREV / DIFF 3종 응답 구조, 업체 권한 범위(authorizedCompanyIds) 제한, 리포트는 Web 전용(App 미제공).
  • 데이터 원천 : TB_EQUIPMENT_DAILY_OPERATION(주·월 집계) + TB_WORKING_HOUR(일 raw) + TB_DATE_SEQ(히트맵 셀 격자) + TB_COMPANY/TB_GROUP(업체·그룹명) + TB_EQUIPMENT/TB_EQUIPMENT_CODE(권한·연료타입) + TB_WORKING_TIME(계획가동시간)
