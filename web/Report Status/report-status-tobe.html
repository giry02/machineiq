TO-BE 개선 사항
  • 개선 본문 업체 선택 — 전역 조회 대상을 제거하고 기간 조회 바로 아래에서 단일 업체를 선택합니다.
  • 삭제 지표 카드 하단 표 제거 — 카드와 같은 값을 반복하던 전월/금월 표를 없애고, 세부 수치는 차트 hover로 확인합니다. 운영률·배터리 충전 횟수처럼 해석이 모호한 항목도 함께 정리했습니다.
  • 신규 제공 지표를 6종으로 확정 — 운영효율 · 충격횟수 · 연료소비량 · 배터리 충전량 · 운행거리 · 운행시간.
  • 신규 카드 값과 차트 값의 정합 — 카드 수치는 일자별 값의 합계(충격 · 거리 · 시간) 또는 평균(효율 · 연비 · 충전량)으로 계산해 차트와 어긋나지 않습니다.
  • 신규 월 조회에서 가로 스크롤 제거 — 막대 폭을 좁혀 31일을 화면 너비에 맞추고, 막대 위 수치 라벨 대신 hover 툴팁으로 전월 · 금월 · 증감을 보여줍니다.
