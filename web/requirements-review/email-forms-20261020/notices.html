조회된 공지가 없습니다.

공지 등록 후 어떻게 보이나요?

현재 받아둔 소스는 관리자 등록 → 모바일 알림에서 직접 ‘공지 조회’ → 목록 → 상세 방식입니다. 플릿 웹 진입 화면과 로그인 자동 팝업은 확인되지 않았습니다.

‘상단 고정’은 목록 순서이며 팝업이 아닙니다. 공지 종류·대상·게시 기간·상단 고정·노출 방식·이메일/PUSH 채널은 서로 다른 설정입니다.

이 시안은 기존 등록 기능을 재사용할 사용자 조회 화면을 검토하는 용도입니다. AWS나 실제 등록 데이터에 연결하지 않습니다. 개인 휴면 사전 안내는 공개 공지 목록에 게시하지 않습니다.
