# 웹·모바일 공통 메일 모음

[전체 메일 확인](https://giry02.github.io/machineiq/web/requirements-review/email-forms-20261020/)

메일은 모바일 전용이 아닌 웹·모바일 공통 기능이다. 각 화면은 권한에 맞는 발송 API를 요청하고, 템플릿 선택·언어·수신 주소 확인·실제 발송은 백엔드 공통 메일 영역에서 처리하는 기준이다. 어드민 2차 인증은 내부 관리자 요청 권한을 유지하고, 리포트 생성은 리포트 업무에서 처리한다.

총 8개 분류·12종 메일이며, 역할·언어·리포트 데이터 상태를 포함한 표시 예시는 67개다. PC·375px·320px는 같은 메일의 수신 화면 너비를 확인하는 기능이지 서로 다른 메일 서비스가 아니다. 모든 종류의 모든 언어를 공개했다는 의미는 아니다.

## 원본과 게시 범위

- 일반·인증·휴면·신규 안내 메일 외곽의 단일 원본은 `email-templates-20260926/source/email-core.cjs`이다. 리포트와 같은 전체 주황색 헤더·흰색 로고·16px 외곽 라운드와 모서리 잘림 처리를 사용한다. 기존 600px 폭·본문·푸터는 유지한다.
- 모음의 본문은 기존 일반·휴면/인증·월간리포트 원본에서 `scripts/build-email-gallery.cjs`로 생성한다. 모바일 전용 복사본이나 별도 발송 모듈을 만들지 않는다.
- `preview/`의 이름·수신인·인증번호·임시 비밀번호·리포트 수치는 검토용 예시다. 이 페이지에는 실제 메일 발송 기능과 인증 키가 없다.
- 2026-10-22 변경은 공통 메일 안내 정리, 누락된 라운드 보완과 두 신규 메일 시안의 GitHub 게시만 포함한다. AWS CodeCommit, 실제 서버 발송용 템플릿, 발송 설정과 모바일 앱 소스는 이번에 변경하지 않는다.
- 기존 주소 및 화면 ID `MHMIQ-COM-015`·`MHMIQ-COM-016`, 메일 식별자 `MIQ-MAIL-001~004`를 유지한다. 새 메일 식별자는 휴면 사전 안내 `MIQ-MAIL-005`, 약관 변경 `MIQ-MAIL-006`이다. 새 서비스 화면은 추가하지 않았다.

## 신규 안내 메일의 백엔드 연결 준비

현재 두 신규 메일은 발송 기능이 아닌 검토용 HTML 시안이다. 기존 공통 메일 서비스에 메일 종류·필수 값·업무 트리거를 추가하는 작업이 필요하며, 별도 모바일 발송 서비스를 만들지 않는다.

- 휴면 전환 사전 안내: 사용자 확정 휴면 기준은 90일이다. 최근 로그인일, 전환 예정일과 등록 이메일은 서버에서 조회·계산한다. 사전 안내를 며칠 전에 몇 회 보낼지는 미확정이므로 임의의 7일/30일로 고정하지 않는다. 발송 직전 재로그인·계정 상태를 확인해 전환 대상에서 제외된 계정에 보내지 않고, 계정+예정일 기준 중복 발송을 방지한다. 로그인을 실제로 완료했는지로 휴면 여부를 재판정하며, 메일 열람만으로 휴면을 해제하지 않는다.
- 이용약관 변경 안내: 확정된 변경 내용·공지일·시행일·변경 전후 약관 URL을 공급한다. 적용 약관과 법무/업무 승인에 따른 공지 기한·대상·채널을 설정하며, 시안에서 특정 법정 통지 기한이나 무응답 동의를 확정하지 않는다. 별도 동의가 필요한 개정인지도 정책에서 결정한다. 약관 식별자+개정 버전+수신자+메일 종류/사건 기준으로 중복 발송을 방지하고 결과·실패·재시도를 기존 발송 이력에 남긴다.
- 수신자·등록 언어 선택, 발송 권한·제한·키 관리는 기존 백엔드 공통 메일을 사용한다. 공지 메일과 광고성 마케팅 수신 동의를 같은 옵션으로 처리하지 않는다. 실제 분류와 통지 문구는 승인된 약관/정책에 맞춰 확정한다.
- 날짜·이름·사용자 ID·변경 내용은 검토용 예시다. 실제 발송을 시작하기 전 백엔드 연결, 발송 정책 및 번역 검토와 수신함 테스트가 별도로 필요하다.
