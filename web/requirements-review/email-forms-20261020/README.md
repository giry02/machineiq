# 웹·모바일 공통 메일 모음

[전체 메일 확인](https://giry02.github.io/machineiq/web/requirements-review/email-forms-20261020/)

메일은 모바일 전용이 아닌 웹·모바일 공통 기능이다. 각 화면은 권한에 맞는 발송 API를 요청하고, 템플릿 선택·언어·수신 주소 확인·실제 발송은 백엔드 공통 메일 영역에서 처리하는 기준이다. 어드민 2차 인증은 내부 관리자 요청 권한을 유지하고, 리포트 생성은 리포트 업무에서 처리한다.

## 확인할 수 있는 종류

| 분류 | 포함 내용 | 현재 공개 시안 언어 |
| --- | --- | --- |
| 회원가입 완료 | 고객 대표·직원, 딜러 대표·직원, 내부 사용자 5종 | 한국어 |
| 이메일 인증번호 | 가입·비밀번호 찾기용 인증번호 | 한국어 |
| 비밀번호 찾기 | 임시 비밀번호 안내 | 한국어 |

| 어드민 로그인 2차 인증 | 내부 관리자 이메일 인증번호 | 한국어·영어 |
| 월간리포트 | 정상·실제 0·미수집·부분 수집·비교 전월 없음 | 8개 언어 |

총 6개 분류·10종 메일이며, 역할·언어·리포트 데이터 상태를 포함한 표시 예시는 51개다. PC·375px·320px는 같은 메일의 수신 화면 너비를 확인하는 기능이지 서로 다른 메일 서비스가 아니다. 모든 종류의 모든 언어를 공개했다는 의미는 아니다.

## 원본과 게시 범위

- 일반·인증·휴면 메일 헤더의 단일 원본은 `email-templates-20260926/source/email-core.cjs`이다. 리포트와 같은 전체 주황색 헤더·흰색 로고를 사용한다.
- 모음의 본문은 기존 일반·휴면/인증·월간리포트 원본에서 `scripts/build-email-gallery.cjs`로 생성한다. 모바일 전용 복사본이나 별도 발송 모듈을 만들지 않는다.
- `preview/`의 이름·수신인·인증번호·임시 비밀번호·리포트 수치는 검토용 예시다. 이 페이지에는 실제 메일 발송 기능과 인증 키가 없다.
- 2026-10-22 변경은 공통 메일 안내 정리와 GitHub 게시만 포함한다. AWS CodeCommit, 실제 서버 발송용 템플릿, 발송 설정과 모바일 앱 소스는 이번에 변경하지 않는다.
- 기존 주소 및 화면 ID `MHMIQ-COM-015`·`MHMIQ-COM-016`, 메일 식별자 `MIQ-MAIL-001~004`를 유지한다.
