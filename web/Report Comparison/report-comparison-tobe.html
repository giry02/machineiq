지표별로 가장 좋은 값을 최적 배지와 옅은 브랜드 강조로 표시합니다. 충격횟수 · 연료소비량은 낮을수록 좋은 지표입니다.
운영효율
TO-BE 개선 사항
  • 삭제 좌측 내비게이션 제거 — 리포트는 업체 단위 화면이므로 상단에서 업체를 고르고 화면 전체 폭을 데이터에 사용합니다.
  • 신규 비교 업체는 최대 3개 — ＋ / － 로 추가 · 제거하며, 이미 고른 업체는 다른 칸에서 선택할 수 없습니다. 업체마다 색을 부여해 표 · 범례 · 그래프가 같은 색으로 연결됩니다.
  • 신규 지표를 6종으로 확정 — 운영효율 · 충격횟수 · 연료소비량 · 배터리 충전량 · 운행거리 · 운행시간. 근로시간 기반 운영률 · 토/일요일 근무 · 배터리 충전 횟수는 제거했습니다.
  • 신규 지표별 최우수 업체 강조 — 표에서 가장 좋은 값을 색으로 구분하고, 낮을수록 좋은 지표(충격 · 연비)는 기준을 반대로 적용합니다.
  • 신규 월 조회에서 가로 스크롤 제거 + hover 툴팁 — 한 시점의 모든 업체 값을 한 번에 비교합니다. 집계 전 구간은 선을 잇지 않습니다.
  • 유지 업체 추가 · 제거 방식, 우측 상단 일 / 주 / 월 기간 조회, 지표 탭 전환, 업체별 라인 비교.
