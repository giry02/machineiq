현재 언어가 어느 계정 값으로 저장되는지 화면에 표시되지 않으며, 계정 저장은 로그인 성공 시점에만 일어납니다.
② 비밀번호 변경 — 로그인 화면에서만 가능
로그인 후에는 비밀번호를 바꿀 화면이 없습니다. 변경하려면 로그아웃 → 로그인 화면 → 비밀번호 찾기 → SMS 인증 → 임시 비밀번호 발급 → 재로그인 → 강제 변경 화면 순서를 거쳐야 합니다.
비밀번호 규칙(12자 이상 · 숫자+영문+특수문자)은 변경 화면에서 오류 메시지로만 알려주고, 마지막 변경일과 경과 일수는 어디에도 표시되지 않습니다. ROLE_ADMIN은 90일이 지나면 로그인 시점에 강제 변경 화면을 만나게 됩니다.
③ 내 정보 · 알림 · 앱 푸시 — 관리기능 › 사용자 수정 모달 (ROLE_ADMIN 전용)
본인 계정이라도 이 모달에 들어가려면 ROLE_ADMIN 권한이 필요합니다. 현재 계정(박민아 · ROLE_FLEET)은 접근할 수 없어 이름 오타 수정, 연락처 변경, 알림 끄기까지 모두 관리자에게 요청해야 합니다.

로그아웃 (GNB 우측 텍스트)
AS-IS 현황 및 개선 포인트
  • 현행 마이페이지가 없어 본인 이름 오타·연락처 변경조차 관리기능 › 사용자에 접근 가능한 ROLE_ADMIN에게 요청해야 하고, 관리자가 대신 수정합니다.
  • 현행 로그인 후 비밀번호를 바꿀 화면이 없어 로그아웃 → 비밀번호 찾기 → 임시 비밀번호 → 재로그인 경로를 강요합니다. 마지막 변경일·경과 일수가 보이지 않아 ROLE_ADMIN은 90일 초과 시 로그인 시점에 갑자기 강제 변경 화면을 만납니다.
  • 현행 언어 변경이 GNB 드롭다운에만 있고 계정 저장 시점(로그인 성공)이 화면에 설명되지 않아, 앱과 웹의 언어가 서로 달라 보이는 문의가 반복됩니다.
  • 현행 알림 수신 3항목(MESSAGE_SHOCK_YN · MESSAGE_ERROR_YN · EMAIL_REPORT_YN)과 앱 푸시 5항목(TB_USER_APP)을 관리자만 수정할 수 있어, 본인이 원치 않는 충격·에러 알림을 스스로 끌 수 없습니다.
  • 현행 로그인 일시·IP 이력 조회 화면이 없어 본인이 이상 접속을 확인할 수 없고, 세션 자동 만료 규칙도 안내되지 않아 작업 중 로그아웃을 장애로 인식합니다.
  • 현행 설정이 GNB · 로그인 화면 · 관리기능 › 사용자 3곳에 흩어져 있어, 신규 사용자는 어떤 설정을 어디서 바꾸는지 스스로 찾지 못합니다.
  • 데이터 원천 : TB_USER(USER_NAME · TELNO · EMAIL · PASSWORD · ROLE_ID · GROUP_ID · MENU_GROUP_ID · MESSAGE_SHOCK_YN · MESSAGE_ERROR_YN · EMAIL_REPORT_YN) + TB_USER_APP(PUSH_ALARM_YN · SHOCK_WARNING_YN · VEHICLE_WARNING_YN · BATTERY_WARNING_YN · MARKETING_YN) + TB_USER_HISTORY(변경 이력, 조회 화면 없음) + TB_COMPANY · TB_GROUP(소속 표시)
