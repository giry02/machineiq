AS-IS 현황 및 개선 포인트
  • 현행 차량 배정이 행 단위 1대씩만 가능해 18대를 옮기려면 18번 저장해야 하고, 저장마다 목록이 새로고침되어 위치를 잃습니다.
  • 현행 그룹 삭제 시 소속 차량·사용자가 어떻게 처리되는지 안내가 없습니다. 삭제 후 차량이 미배정으로 떨어졌는지 확인할 방법이 없습니다.
  • 현행 근무시간과 충격 임계값(SHOCK1~5) 설정이 업체·그룹·차량 화면에 흩어져 있고, 어느 값이 실제 적용되는지(상속 여부) 화면에서 알 수 없습니다.
  • 현행 접근 권한 매트릭스에 저장 전 미리보기·영향 사용자 안내가 없어 체크를 잘못 해제하면 실제 사용자가 메뉴를 잃은 뒤에 발견됩니다.
  • 현행 목록에 Geofence 수만 숫자로 표시되고 해당 그룹의 Geofence 관리 화면으로 이동할 링크가 없습니다.
  • 데이터 원천 : TB_GROUP(그룹명/위치/Timezone) + TB_WORKING_TIME(그룹 근무시간, SETTING_TYPE_CODE='G') + TB_EQUIPMENT.GROUP_ID(차량 배정) + TB_USER.GROUP_ID / MENU_GROUP_ID(사용자·메뉴 권한) + TB_GEOFENCE(그룹별 구역)
