TO-BE 개선 사항
  • 삭제 좌측 내비게이션 제거 — 리포트는 업체 단위 화면이므로 상단에서 업체를 고르고 화면 전체 폭을 격자에 사용합니다.
  • 삭제 운영률 탭 제거 — 근로시간 기입값에 의존하던 지표라 다른 리포트 화면과 동일하게 빼고, 대신 지표 6종(운영효율 · 충격횟수 · 연료소비량 · 배터리 충전량 · 운행거리 · 운행시간)을 히트맵으로 볼 수 있게 했습니다.
  • 신규 조회 기간의 날짜별 값을 표시합니다 — 수집되지 않은 값은 실제 0과 구분할 수 있도록 '-' 와 옅은 배경으로 구분합니다.
  • 신규 색 구간을 지표 단위로 계산 — 조회 결과의 최댓값을 4구간으로 나눠 범례에 실제 값 범위를 함께 표기합니다.
  • 신규 셀 hover 툴팁 — 좁은 칸에서 잘리는 숫자를 업체 · 일자 · 지표 · 값으로 정확히 보여줍니다. 월 조회도 가로 스크롤 없이 너비에 맞춥니다.
  • 유지 업체 ＋ / － 추가 · 제거(최대 5), 업체 × 일자 격자와 색상 범례, 우측 상단 일 / 주 / 월 기간 조회.
