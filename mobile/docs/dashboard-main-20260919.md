## 권한·집계·이동

- 대표: 업체 전체 차량, 그룹별 운영 비교 및 작업시간/대기비율 정렬.
- 직원: 배정 그룹의 차량 상태·에러 발생·현재 소모품·오늘 작업 실적·최근 7일만 표시. 다른 그룹 정보와 그룹 정렬 없음. 샘플 배정은 물류1팀 3대이며 하드코딩하지 않고 `M.assignedGroup`/`M.scope` 사용.
- 에러는 금일 00:00~완료된 1시간 집계 시각의 **발생 건수(건)**. 소모품은 날짜와 무관한 **현재 관리 항목 수(개)**. 미연결을 미가동으로 합산하지 않는다.
- 오늘 작업은 현재 연결 차량의 완료 시간대 실적. 최근 7일은 오늘을 제외한 일자별 리포트 어댑터 값; 과거 수신 실적 포함. 미수신과 0 구분.
- 에러/교체 필요/임박 → 기존 서비스 탭·필터, 상태 → 차량 목록, 그룹/일자 → 업무 리포트. 직원의 모든 목적지는 배정 그룹 범위 유지. 프런트 목업 권한이며 실제 서버에서도 별도 권한 검증 필요.
