## 반영 구분

로컬 고객 모바일 HTML만 반영. 격리 QA 서버는 원본 데이터 파일을 바꾸지 않고 응답 복사본에만 누락값을 주입한다. 실제 API가 없는 현재 구조에서 “다시 불러오기”는 페이지 재로딩이다. 실제 서버 타임아웃/복구·오프라인 캐시·실기기 네트워크 검증 완료를 의미하지 않는다.

WEB, 별도 Vue, 서버/API, GitHub Pages, ZIP, APK/iOS는 갱신하지 않음. 화면 등록부와 Figma/FigJam 반영 대기 기록만 갱신하며 원격 보드는 변경하지 않음.
