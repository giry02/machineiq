## r46 상세 기능

에러는 별도 상세 화면 없이 목록의 등록 PDF 다운로드 아이콘만 제공합니다. 없는 파일은 `-`입니다. P0003 PDF는 웹 정보를 옮긴 시연 참고자료이며 정비 매뉴얼이 아닙니다.

리튬 차량 상세와 배터리 화면에는 웹과 같은 온도·충전·배터리 상태, 스마트 충전 켜기/끄기·시작/종료·저장을 제공합니다. 22→06은 8시간, 같은 시각은 24시간입니다. 역할/VIN별 고객 전용 브라우저 저장이며 실제 충전 명령은 없습니다. 납산/엔진은 기존 화면을 유지합니다.

차량 상세와 충격 화면은 민감(Lv3·1.2g)·주의(Lv4·1.8g)·경고(Lv5·2.5g) 건수를 구분합니다. 강도는 시연 이벤트이며 기존 총수와 일/월 합계가 일치합니다. 수신되지 않은 값은 0이 아닌 `-`입니다. 최신 정의는 JSON 등록부이며 이전 엑셀/스타일 가이드는 제작 시점의 스냅샷입니다.
