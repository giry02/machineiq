# MACHINE IQ 고객 모바일

2026-09-20 dashboard v5. `mobile` 폴더만으로 정적 호스팅하는 HTML 프로토타입입니다. 현재 대표/직원 차트형 대시보드, 14px 세부 글자, 일·주·월 조회, 정수 반올림, 항목별 상세 연결을 포함합니다. 대표는 업체 전체, 직원은 배정 그룹만 조회합니다. 카드 제목의 텍스트 링크는 배경 없이 글자색만 강조하고 하단 ‘프로토타입 데이터’ 문구는 제거했습니다. 데이터는 여전히 시연용이며 실제 서버 연결을 뜻하지 않습니다.

- 대표 메인: `index.html#home?role=customer_owner`
- 직원 메인: `index.html#home?role=customer_staff`
- 이전 메인 보관: `dashboard-backup-20260919.html#home?role=customer_owner`
- 변경 기록: `docs/dashboard-main-20260919.md`

기존 고객 로그인·가입·비밀번호 찾기, 소모품 교체 처리, 리튬/납산 배터리 아이콘 구간색 등은 유지합니다.

## 실행

Node.js 22 이상에서 저장소 루트 기준:

```sh
node mobile/serve.cjs
```

브라우저에서 `http://localhost:8806/login.html`을 엽니다. 같은 포트를 사용 중이면 `node mobile/serve.cjs 8810`처럼 다른 포트를 지정합니다. 별도 패키지 설치나 빌드가 필요하지 않습니다. 정적 호스팅에서는 `mobile/login.html`로 진입합니다.

## 화면

- 로그인: `login.html`
- 회원가입: `signup.html` — 소속정보에서 고객 대표/고객 직원 선택. 직원은 장비 연결 정보 입력을 생략합니다.
- 비밀번호 찾기: `find-password.html`
- 고객 홈: `index.html#home`
- 알림: `index.html#notifications` — 전체/충격/차량 에러/배터리, 유형별 받은 내역 건수. 다른 유형 수신 시 기타 탭.
- 설정: `index.html#settings` — 화면 확인용 고객 역할, PUSH 설정, 로그아웃.

서비스는 정비·에러 기간 이력과 소모품 현재 상태를 구분합니다. 요약정보·업무 현황·운영효율·차량 상세는 기존 고객/그룹 범위를 유지합니다. 날짜는 한국 시간의 오늘과 정시를 기준으로 표시합니다.

## 구현 범위

실제 인증·회원가입·이메일/SMS/PUSH 발송·서버 로그아웃 API는 연결하지 않았습니다. 기기 PUSH 권한을 변경하지 않습니다. 로그인 후 직접 주소 접근을 차단하는 보안 구현도 아닙니다.

고객 대표만 소모품을 개별/전체 선택하고 확인 후 0H·정상 처리할 수 있습니다. 관련 집계도 갱신되며 실행 취소가 가능합니다. 직원·그룹장은 조회 전용입니다. 실제 장비나 서버에 반영하지 않으며 새로고침하면 원래 데이터로 돌아갑니다.

지도 API 키와 `map-config.local.js`는 공개 파일에서 제외합니다. 키가 없는 공개 환경에서는 지도 안내와 Google 지도 외부 열기를 제공합니다. 지도 API를 사용하려면 게시 주소로 제한된 키를 별도로 설정해야 합니다.

기존 `downloads/MACHINE_IQ_MOBILE_HTML_20260913_r46.zip`은 **2026-09-13 보관본**이며 이번 최신 화면을 포함하지 않습니다. 이번에는 정적 웹 화면만 갱신했고 ZIP/APK/iOS를 재생성하지 않았습니다.

`docs/`에 메뉴·페이지 구조도 엑셀과 스타일 가이드 PDF를 함께 제공합니다. 두 문서는 소모품 Reset 추가 전 스냅샷이며, 최신 팝업·권한 정의는 JSON 등록부와 `supply-reset.md`를 참고합니다.

화면 검수용 기본 비밀번호는 `password12!@`, 이메일 인증 코드는 `123456`입니다. 회원가입은 승인대기, 임시 비밀번호 로그인은 새 비밀번호 설정 흐름을 표시합니다. 비밀번호 재설정 결과는 실제 계정에 저장되지 않습니다. 로컬 상태는 고객 전용 키만 사용하며 로그아웃 시 아이디 저장이나 다른 앱 정보는 삭제하지 않습니다.

## 폴더 및 검사

`shared/`: 기존 모바일 공통 CSS·아이콘·로고, `assets/`: 폰트·파비콘, `data/`: 화면용 차량 자료, `docs/screen-registry.json`: 화면 정의, `manifest.json`: 배포 파일 해시.

```sh
node mobile/tests/package.cjs
node mobile/tests/dashboard.cjs
node mobile/tests/auth.cjs
node mobile/tests/supply-reset.cjs
node mobile/tests/soc.cjs
node mobile/tests/error.cjs
node mobile/tests/lithium-shock.cjs
```

검사는 파일/자산/경로/문법 및 로컬 인증 흐름을 확인합니다. 브라우저 시각 비교와 실제 서버 검증은 포함하지 않습니다. 백업·작업 로그·비활성 시안·다른 웹 화면은 이 폴더에 포함하지 않았습니다.


## r46 상세 기능

에러는 별도 상세 화면 없이 목록의 등록 PDF 다운로드 아이콘만 제공합니다. 없는 파일은 `-`입니다. P0003 PDF는 웹 정보를 옮긴 시연 참고자료이며 정비 매뉴얼이 아닙니다.

리튬 차량 상세와 배터리 화면에는 웹과 같은 온도·충전·배터리 상태, 스마트 충전 켜기/끄기·시작/종료·저장을 제공합니다. 22→06은 8시간, 같은 시각은 24시간입니다. 역할/VIN별 고객 전용 브라우저 저장이며 실제 충전 명령은 없습니다. 납산/엔진은 기존 화면을 유지합니다.

차량 상세와 충격 화면은 민감(Lv3·1.2g)·주의(Lv4·1.8g)·경고(Lv5·2.5g) 건수를 구분합니다. 강도는 시연 이벤트이며 기존 총수와 일/월 합계가 일치합니다. 수신되지 않은 값은 0이 아닌 `-`입니다. 최신 정의는 JSON 등록부이며 이전 엑셀/스타일 가이드는 제작 시점의 스냅샷입니다.
