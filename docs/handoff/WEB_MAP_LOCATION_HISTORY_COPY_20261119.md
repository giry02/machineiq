# WEB 지도 위치 이력 명칭 및 우측 안내 정리

2026-11-19 사용자 요청에 따라 기존 지도 화면 MHMIQ-MAP-001과 메뉴 map을 유지하여 세 곳만 변경했다.

|구분|변경 전|변경 후|
|---|---|---|
|지도 표시 모드|차량 경로 조회|위치 이력|
|기간 확정 버튼|경로 조회|조회|
|위치 이력의 우측 회색 안내|선택 차량 식별자 · 날짜 · 이동 경로|미표시, 텍스트도 빈 값|

## 수정 파일과 구현

- 공통 `_shared/map-management-enhancements.js`의 toolbar 생성과 `renderRoute()`만 수정했다. 초기 route=1 진입부터 회색 안내를 비우고 숨기며, 현재 위치로 전환하면 원래 장비목록 선택 안내를 복원한다. 기존 VIN/날짜 조합 문자열 생성은 제거했다.
- 이 공통 파일을 불러오는 지도·업체/그룹/사용자/차량 관리 5개 HTML의 자산 캐시 참조만 갱신했다. 관리 화면의 기능·본문은 변경하지 않았다.
- 로컬 다국어는 기존 `web.extra0036` 키의 8언어 명칭과 key-map을 갱신하고 단일 JSON 원본에서 messages-en.js·메타데이터를 재생성했다. 조회는 기존 `common.apply` 번역을 사용한다. 기존 한글 고정 GitHub 게시 프로필을 유지한다.
- 지도 크기·GNB/LNB·색상·폰트·여백·마커·차량 목록·조회 범위는 그대로다. 날짜·일/주/월은 초안이며 조회/Enter에서 확정하는 방식, routeVin 복원·권한 범위를 유지한다.

## 확인 결과와 범위

- 기존 WEB 검사 **322/322 통과**, 그 안의 지도 계약 검사40개 포함. 활성49페이지·런타임190파일 및 생성 원본 일치.
- 격리 게시본의 고객 대표/직원·딜러 대표/직원·내부사용자 5구분에서 현재 위치/위치 이력 전환, 차량 선택, 날짜 초안 미조회, 조회1회, 새로고침 복원, 회색 안내 미표시를 확인했다. JS 오류·자산404 없음.
- 동일 기준시각·1440/1878px에서 전후 비교하여 지도·장비목록·GNB/LNB 기하, 목록 내용, CSS 참조가 동일하다. 화면 캡처를 함께 확인했다. 요청한 라벨 길이로 바뀌는 컨트롤의 가로 위치는 자연스럽게 줄어든다.
- canonical 로컬의 나머지7언어에서도 새 위치 이력 명칭·기존 조회 번역 및 회색 안내 제거를 확인했다.
- 브라우저 회귀는 외부 Google 인증을 기본 지도 fallback으로 고정해 검증했다. 실제 Google 인증/API·서버 GPS 연결의 성공을 새로 주장하지 않는다. 해당 연결·좌표 도표는 변경하지 않았다.
- 근거: `.tmp/web-map-copy-20261119/browser.json`, `canonical-browser.json`, 전후4쌍 캡처, `source-tests.log`. 별도 ZIP 없음.
- WEB 로컬 및 사용자가 요청한 GitHub 정적 게시 범위다. 모바일·AWS·개발 소스·가입/NICE·미게시 어드민·원격 FigJam은 미변경이다. 로컬/공개본의 서로 다른 차량등록 코드를 통째로 복사하지 않고 지도 수정 부분만 각각 반영했다.
